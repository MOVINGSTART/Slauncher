## SLauncher

### 전체

- `Ctrl + H`로 SLauncher 도우미 UI 표시 / 숨김
- 도우미 UI 별도 접기 / 펼치기
- StarCraft 실행 및 자동 감지
- StarCraft 종료 시 SLauncher 자동 종료
- SLauncher 종료 시 연동된 보조 프로그램 자동 종료
- StarPing 자동 백그라운드 실행
- 자동 업데이트 지원
- Google 계정 로그인 지원
- 서버 연결 상태 확인
- 사용자별 설정 자동 저장
- 일반 사용자 / 관리자 권한 분리
- SLauncher 보호 엔진 및 무결성 검사

## SLauncher 전용방

방 제목에 **`#S` 또는 `#s`**를 넣으면 SLauncher 전용방 기능을 사용할 수 있습니다.

예시:

- `빨무 #S`
- `초보방 #s`
- `헌터 3:3 #S`

### 동작

- 같은 방 사용자의 SLauncher 인증 상태 확인
- SLauncher 사용자는 정상 입장
- 미인증 사용자는 재확인 후 자동 처리
- 방장 / 컴퓨터 플레이어 제외
- 서버 통신 오류만으로 사용자를 강퇴하지 않음
- 입장 직후 인증 동기화를 위한 유예시간 적용
- `#Star`, `#squad`와 같은 일반 단어는 전용방으로 오인하지 않음

# StarPing

SLauncher 실행 중 StarCraft가 감지되면  
**StarPingP1P8Auto_v5_13_3.exe**가 자동으로 백그라운드 실행됩니다.

### 기능

- 플레이어별 미니맵 Ping 색상 표시
- LOCAL / REMOTE Ping 판별
- P1~P8 송신자 자동 판별
- 사용자 지정 색상 연동
- StarCraft 실행 시 자동 시작
- 비정상 종료 시 자동 재실행
- 별도 콘솔창 표시 안 함
- SLauncher 종료 시 같이 종료
- StarCraft 종료 시 같이 종료

StarPing에서 생성하는 Capture / Log 파일은 SLauncher 폴더에 계속 쌓이지 않도록 임시 영역에서 처리됩니다.

# 실행 방법

1. SLauncher를 실행합니다.
2. 필요한 경우 Google 계정으로 로그인합니다.
3. Battle.net / StarCraft를 실행합니다.
4. StarCraft가 감지되면 SLauncher 기능이 자동 연결됩니다.
5. StarPing도 자동으로 백그라운드 실행됩니다.
6. 게임 또는 로비에 입장하면 관련 기능이 자동 활성화됩니다.

StarPing을 사용자가 별도로 직접 실행할 필요는 없습니다.

관리자 페이지는 일반 사용자 접근을 제한하도록 구성되어 있습니다.

# 안내

- 네트워크 상태가 좋지 않은 사용자는 Ping / LAG 판정이 일시적으로 부정확할 수 있습니다.
- 블랙리스트 자동 강퇴는 방장 권한이 있는 경우에만 실제 강퇴가 가능합니다.
- 화이트리스트 사용자는 자동 처리 대상에서 제외됩니다.
- 서버 연결 장애만으로 SLauncher 사용자를 차단하거나 강퇴하지 않습니다.
- StarPing은 SLauncher와 함께 자동 실행되며 별도 콘솔창은 표시되지 않습니다.
- StarCraft가 완전히 종료되면 연동된 StarPing과 SLauncher도 함께 종료됩니다.
- 일부 감지 결과는 자동 판정만 믿기보다 실제 게임 상황과 함께 확인하는 것을 권장합니다.
- 패킷 분석 기록은 관리자 제출이나 문제 분석에 사용할 수 있습니다.
- `#S / #s` 전용방 기능은 SLauncher 서버 인증이 정상 연결되어 있을 때 사용 가능합니다.
